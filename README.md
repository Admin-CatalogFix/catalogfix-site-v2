# CatalogFix website v2

Preview build of the new CatalogFix site, built from `CATALOGFIX_WEBSITE_BRIEF.md`.

- **Preview:** https://admin-catalogfix.github.io/catalogfix-site-v2/
- **Live site (unchanged):** https://catalogfix.com, served from the separate `catalogfix-website` repo

The site lives in `docs/` (three pages: Home, Who We Are, Our Team). GitHub Pages publishes only that folder, so the brief at the repo root is not part of the website.

See `CLAUDE.md` for how to edit, what's still a placeholder, and the steps for moving the domain over.
